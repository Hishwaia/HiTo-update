# HiTo — таблицы, оси и оформление для AutoCAD и Civil 3D

Набор утилит, ускоряющих формирование исполнительной геодезической документации: таблицы-легенды
из DWG-шаблона, сетки осей по ГОСТ с нумерацией и размерными цепочками, обозначения проёмов,
листы из заготовок, калькулятор и проверка оформления схем.

**Версия 1.5.0** · выпущена 2026-07-30 · требуется Civil 3D 2027 и новее

## Скачать

**[HiTo Setup v1.5.0.exe](HiTo%20Setup%20v1.5.0.exe)**

## Установка

1. Закройте AutoCAD / Civil 3D — работающая программа держит файлы плагина.
2. Запустите установщик. Он просит права администратора: плагин ставится для всех пользователей.
3. Windows покажет предупреждение **«Неизвестный издатель»** — так и должно быть. Установщик не
   подписан сертификатом издателя (он покупной), а SmartScreen предупреждает о любом неподписанном
   файле независимо от содержимого. Нажмите «Подробнее» → «Выполнить в любом случае».
   Убедиться, что файл не подменён по пути к вам, можно по контрольной сумме — см. ниже.
4. Запустите Civil 3D. На ленте появится вкладка **HiTo**.

Обновление ставится поверх предыдущей версии, снимать её вручную не нужно. Настройки, шаблон
таблиц и заготовки листов остаются на месте: они лежат в профиле пользователя и установщиком не
перезаписываются.


Проверить скачанный файл в PowerShell:

```powershell
Get-FileHash "HiTo Setup v1.5.0.exe" -Algorithm SHA256
```

Совпала — файл именно тот, что выпущен. Не совпала — не запускайте его и скачайте заново.

## Проверка обновлений

Плагин себя не обновляет: установщик требует прав администратора, а работающий AutoCAD держит
файлы плагина. Узнать о новой версии можно вручную — лента **HiTo** → панель «Справка» →
**О приложении** → «Проверить обновление». Плагин читает `version.json` из этого репозитория и
сообщает, есть ли что-то новее установленного.
